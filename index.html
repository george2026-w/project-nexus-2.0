About this directory

PROJECT NEXUS links to games hosted by other websites; it does not copy or host their games. Some sites may show ads, ask for an account, or work better on a computer. Check a site's rules and ask a parent or trusted adult if you're unsure. This directory does not bypass school or network restrictions.

The library starts with a smaller set of named, direct links rather than filling the page with made-up games. It can grow toward 1,000 as more real game pages are added and checked.
